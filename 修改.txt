2. 新增函数：blur_detector
功能：检测视频的模糊程度

算法：拉普拉斯方差（Laplacian Variance）

清晰图像：边缘锐利 → 拉普拉斯响应方差大

模糊图像：边缘平滑 → 拉普拉斯响应方差小

输入：frames_rgb — [T, H, W, 3] 格式的 RGB 帧序列

输出格式：

python
{
    "score": 0.0~1.0,    # 模糊程度，0=清晰，1=最模糊
    "level": "无/轻/中/重",  # 分级
    "detail": {           # 附加信息
        "laplacian_var_mean": float,   # 帧间拉普拉斯方差均值
        "laplacian_var_std": float,    # 帧间方差标准差
        "per_frame": [float, ...]      # 每帧的拉普拉斯方差
    }
}
阈值与分级：

拉普拉斯方差	等级
> 150	无
80 ~ 150	轻
30 ~ 80	中
< 30	重
3. 注册到诊断系统
python
# 在 vqa/diagnosis.py 中

register_detector("模糊", BLUR_DETECTOR)
