模型架构与训练信息

🏗️ 模型架构

  • 特征提取器：ResNet-50 多尺度卷积分支
  • 全局分支：ViT-B/16 Token 分支
  • 特征维度：15,872 维
  • 时间聚合：时序池化 + 回归头

📚 训练流程

  • A阶段 (Baseline)：标注视频监督训练 (MSE)
  • B阶段 (半监督)：伪标签迭代优化 (加权MSE)
  • 优化目标：SROCC + PLCC
