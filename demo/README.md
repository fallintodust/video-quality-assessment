# NR-VQA 视频质量评估 Demo（2.0）

无参考视频质量评估演示系统：多模型打分 + 批量评估 + 失真问题反馈（闪烁/噪点/模糊）+ 任务书格式 score.txt + **重新打分**。

> **1.0 → 2.0**：1.0 仅支持单次上传打分；2.0 升级为多模型选择打分，并新增「重新打分」——对已出结果的视频切换模型即可再次评估，无需重新上传。

---

## 2.0 更新说明

### 功能变化总览

| 能力 | 1.0 | 2.0 |
|------|-----|-----|
| 打分模型 | 固定单个模型 | 自研模型 / DOVER / DOVER++ 三选一（卡片式选择） |
| 上传评估 | 单次上传 | 拖拽/点选批量上传，队列逐条评估 |
| 结果卡片 | 仅分数 | 分数 + 模型/量纲 + score.txt 行 + 失真问题反馈 + 「重新打分」按钮 |
| 换模型重评 | 需重新上传 | 卡片一键「重新打分」，服务端复用已暂存视频，无需重新上传 |
| 结果输出 | 界面展示 | 界面展示 + score.txt（任务书格式）下载 |

### 接口说明（相对 1.0 的修改）

- **`POST /api/predict`** —— 保留打分入口，扩展 `model_id` 参数指定模型；打分成功后返回 `video_id`（视频在服务端暂存，供重新打分复用）。
- **`POST /api/predict/{video_id}?model_id=`** —— **2.0 新增**，重新打分接口：对暂存视频用指定模型再次评估，无需重新上传文件；响应结构与 `/api/predict` 一致。暂存视频超过 30 分钟未使用会自动清理，前端会自动回退为重传原文件。
- **`GET /api/models`** —— **2.0 新增**，模型列表（含可用状态、量纲说明）。
- **`GET /api/score/txt?model_id=`** —— **2.0 新增**，输出任务书格式 score.txt。
- **`POST /api/score/reset` / `GET /api/score/history`** —— **2.0 新增**，清空 / 查看打分记录。
- `GET /api/health` —— 保留，健康检查。

### 新增的 UI 组件

- **模型选择卡片区**：展示各模型可用状态、量纲与说明，点击即切换当前打分模型。
- **上传区与评估队列**：拖拽或点选批量加入队列，可移除/清空，统一「开始评估」。
- **结果卡片**：网格展示每段视频的分数、所用模型、量纲、score.txt 对应行与失真问题反馈；卡片底部提供 **「重新打分」按钮**，点击后按当前选中的模型刷新该卡片（无需重新上传）。
- **score.txt 面板**：按模型查看/刷新/下载/清空任务书格式记录。
- **失真问题反馈**：闪烁、噪点、模糊的强度分级展示。
- **模型信息说明区**：折叠展示三个模型的区别。

## 失真检测模块状态

Demo 2.0 结果卡片中的「失真问题反馈」区域集成以下检测模块：

| 失真类型 | 状态 | 检测器 | 说明 |
|---------|------|--------|------|
| **噪点检测** | ✅ 已完成 | `scripts/noise_detectors.py` | 基于 ResNet-50 特征 + 回归头，在合成噪点数据集上训练。当前最优模型（500 视频训练）：SROCC 0.6791 / PLCC 0.5751。支持启发式回退，检测结果输出 0~1 分数及「无/轻/中/重」等级。 |
