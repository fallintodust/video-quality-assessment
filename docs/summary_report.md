## 2. 模型能识别哪些视频质量问题？（能力边界分析）

### 2.1 架构回顾（决定能力边界的关键）

```
视频 -> TSN 均匀抽 8 帧(224x224)
    -> 每帧独立提取 15872 维特征
         CNN 分支: ResNet-50 多尺度(mean/max/std 统计池化 + GAP) = 13568 维
         ViT 分支: ViT-B/16 token 统计池化 = 2304 维
    -> 时间聚合: T 帧特征取【平均】(mean)
    -> 回归头: 15872 -> 512 -> ReLU -> 1 (MOS)
```

**两个决定性的设计事实：**
1. 每帧是**独立**提取空间特征——帧间没有交互
2. 时间聚合是**平均池化**——对帧顺序**置换不变**（把 8 帧打乱顺序，输出完全一样）

由此可以精确推导出能力边界：

### 2.2 能识别 ✓（强）

| 质量失真类型 | 原理 |
|---|---|
| **模糊**（失焦/运动模糊/压缩导致的细节丢失） | 高频能量下降，CNN 浅层边缘响应、ViT patch 纹理 token 均敏感 |
| **压缩块效应/振铃**（blocking/ringing） | 块状结构是局部高频模式，224 分辨率下仍可见 |
| **噪声**（高斯/传感器噪声） | 统计池化中的 std 分量直接编码噪声方差 |
| **曝光异常**（过曝/欠曝） | 亮度直方图偏置，均值特征直接反映 |
| **色彩失真/偏色** | 通道均值与对比度变化 |
| **低频亮度/色度闪烁** | 闪烁帧本身就是失真帧（过亮/过暗/偏色），平均后仍保留失真痕迹——合成闪烁自测 SROCC≈0.92 证实 |

### 2.3 部分能识别 △（弱）

| 质量失真类型 | 原理与局限 |
|---|---|
| **中高频闪烁** | 8 帧采样低于 Nyquist 频率会混叠；若闪烁帧与正常帧平均后失真被稀释，敏感度下降 |
| **冻结/丢帧**（视频卡住） | 帧不足时"最后一帧重复补齐"使输入帧重复，但均值池化**无法感知重复性本身**；只有当冻结帧内容本身失真时才有信号 |
| **块状伪影的空间定位** | 能感知存在，但无法输出"哪个区域坏了"（无质量图输出） |

### 2.4 不能识别 ✗（结构性盲区）

| 质量失真类型 | 为什么 |
|---|---|
| **运动平滑度/抖动/卡顿**（judder、stutter、帧率不连续） | 无光流、无帧差特征；8 帧均匀采样几乎不含运动轨迹信息 |
| **帧间内容不一致但每帧外观正常**（如场景跳变闪烁、白平衡振荡） | 均值池化置换不变：`mean(f1,f2,...)` 无法区分"稳定场景"与"两场景交替" |
| **音频问题** | 模型只吃图像 |
| **分辨率差异**（320p vs 4K 细节丢失） | 全部 resize 到 224×224，精细纹理差异被抹平，只残留"模糊等价的线索" |

**一句话总结：这个模型本质是"逐帧空间失真回归 + 时间平均"，打分的是"平均一帧看起来有多烂"，而不是"视频动起来是否连贯"。** 对于本课程任务书"时域一致性"这一主题，时域维度的建模恰是当前架构最薄弱的一环——这也是后续方向选择的着力点。

## 3. 方向选择建议（按成本排序）

### 3.1 一天内可做（答辩前完全来得及）

1. **时域差分特征**：把均值池化换成 `[mean, std] 拼接`（或加帧差特征）。std 分量直接编码帧间不一致 → 直接补上闪烁/时域一致性盲区。改动 ~10 行，重训几小时即可对比。
2. **光流/帧差分支**：预抽帧时额外存相邻帧差图（或 RAFT 光流），加一个小卷积分支，显式建模运动。成本半天。
3. **T=16 抽帧**：采样密度翻倍，缓解高频闪烁混叠。直接调参重跑。

### 3.2 两三天内可做

4. **时序注意力聚合**（自注意力替代平均池化）：帧间可交互，打破置换不变性。
5. **质量图输出 + 可解释性**（答辩加分项）：把回归头换成 patch 级质量图 + 注意力可视化，"模型能指出哪一帧/哪块区域坏了"——与参考论文 ExplainableVQA 呼应，演示效果好。
6. **消融实验**：仅 CNN / 仅 ViT / 双分支，写进报告。

### 3.3 长期/报告展望

7. RL 扩展（docs/rl_extension.md 已有设计）
8. 官方标注到达后的时域轴对齐（train_lable_test_Tall.txt 提示课程 MOS 可能基于 T 轴）
9. 多模态（音画一致性）
