# 半监督伪标签实验汇报（第一轮实验 + 数据诊断 + 修改方案）

> 日期：2026-09-03 ｜ 作者：Claude ｜ 关联：`docs/summary_report.md`（总结/能力分析）

---

## 1. 实验设计（回顾）

- **(A) Baseline**：3634 标注视频监督训练，双分支架构（15872 维）→ MOS 回归，909 锁定验证集
- **(B) 半监督**：909 个"未标注"视频（其真值只用于验证，不参与训练）按任务书流程：
  - B.1 每轮 5 次独立"训练-打分"→ 均值=伪 MOS、方差=置信度 → 方差 < 0.2 入池
  - B.2 从 baseline 重新出发，用「真标注(w=1.0) + 伪标签池(w=0.5)」微调 10 epochs → 验证集指标
  - 早停：连续 3 轮不提升即停（5 轮上限）

## 2. 各轮结果（趋势：持续下滑）

| 阶段 | SROCC | PLCC | OBJ | 相对 baseline |
|---|---|---|---|---|
| **baseline** | 0.6723 | 0.6723 | **1.3446** | — |
| 轮次 1 | 0.6716 | 0.6271 | 1.2987 | −0.046 |
| 轮次 2 | 0.6454 | 0.5698 | 1.2152 | −0.129 |
| 轮次 3 | 0.6628 | 0.5034 | 1.1662 | −0.178 |
| 轮次 4 | 0.6615 | 0.4719 | 1.1334 | −0.211 |

**实验结束（早停 3/3）：循环内 best = 轮次 1（OBJ 1.2987），全部 4 轮均低于 baseline（1.3446）。**

特征：**SROCC 基本稳住（排序能力未丢），PLCC 单调下滑（数值标定被破坏）**。

## 3. 数据诊断（为什么失败）

### 3.1 伪标签分布 vs 真标注分布（n=905 池）

| | mean | std | min | max |
|---|---|---|---|---|
| 训练真标注（3634） | 3.000 | 0.491 | 1.213 | 4.637 |
| 伪标签池（905） | 3.024 | **0.422** | **1.817** | **5.370** |

- 伪标签 std 比真值**压缩 14%**（0.422 vs 0.491），分数向均值聚集
- 伪标签最低分 1.817——**模型不敢打低分**（真值最低 1.213）
- 伪标签最高分 5.370——**越出 MOS [1,5] 量纲**（无裁剪）

### 3.2 分区间偏差（伪 − 真）

| 真值区间 | 样本数 | 平均偏差 |
|---|---|---|
| 低分（<2.0） | 35 | **+0.559**（严重高估） |
| 中分（2~3） | 404 | +0.190（偏高） |
| 高分（≥3.0） | 466 | −0.157（偏低） |

整体偏差 +0.025 是**高估与低估的巧合抵消**，掩盖了严重的分段系统性偏差。

### 3.3 伪标签质量

- 伪标签与验证真值：Pearson=0.698、Spearman=0.695 → 伪标签**确实携带信号**（不是纯噪声）
- 方差分布：mean=0.0148、75% 分位=0.0164、max=0.198 → 阈值 0.2 **形同虚设**（905/909 全过）

### 3.4 根因结论

> 伪标签是"模型自己的预测"，带有**压缩偏差**（不敢打低分、够不着高分）。以 0.5 权重把压缩过的分数当监督信号回喂，模型学会了"把分数往中间挤"→ 预测值偏离真值（PLCC 崩），但压缩近似保序（SROCC 稳）。阈值 0.2 太松 + 权重 0.5 太重，放大了这一自我确认偏差。

## 4. 数据修改方案（第二轮实验）

| 修改 | 原值 | 新值 | 理由 |
|---|---|---|---|
| 伪标签重标定（`--pseudo-debias`，新实现） | 无 | z-score 对齐真标注分布 | 展开被压缩的分布，恢复尾部 |
| 伪标签裁剪（`--pseudo-clip`，新实现） | 无 | [1,5] | 修复越界（max 5.37） |
| 伪标签权重 `--pseudo-weight` | 0.5 | **0.2** | 降低回喂污染的强度 |
| 方差阈值 `--var-threshold` | 0.2 | **0.05** | 让筛选真正起作用（当前方差普遍 <0.02） |

重标定实现（`vqa/semisup.py::debias_pool`）：每轮 B.1 后对全池做
`mos' = (mos − μ_pool)/σ_pool × σ_train + μ_train`，目标分布只用**训练真标注**估计，绝不碰验证真值。

```bash
python -u scripts/train_semisup.py \
    --data-dir data/divide/videos \
    --labels data/divide/train_lable_train.txt \
    --val-labels data/divide/train_lable_test.txt \
    --baseline runs/divide_baseline --out runs/divide_semisup_v2 \

```

- 判定标准：任一时刻 OBJ 超过 baseline 1.3446 即成功；5 轮 + 早停兜底
- 预计耗时：20 小时左右（速度随电脑使用情况波动）
