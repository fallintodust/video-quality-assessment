# 扩展方向设计：强化学习增强视频质量打分（任务书第九章）

在已训练的视频质量打分模型基础上，引入强化学习（RL），以 PPO 训练一个
打分/增强策略 agent，探索"先增强后打分"能否进一步提升 SROCC/PLCC。

## 整体框架

```
 ┌──────────────────────────────────────────────────────┐
 │  环境 Environment                                     │
 │  状态 s: 视频特征（现有模型提取的 15872 维视频级向量）      │
 │  动作 a: 选择增强算子组合 / 直接输出打分                   │
 │  转移:  增强后的视频 -> 重新提取特征 -> 下一状态            │
 │  奖励 r: 打分与人工标注 MOS 的一致性 + 稳定性/保真度约束    │
 └──────────────────────────────────────────────────────┘
          ▲ 状态/奖励                    │ 动作
          │                             ▼
     PPO Agent（Actor-Critic）       增强算子库
          ▲                             │
          └── 视频增强后的画质 ──────────┘
```

## 关键设计（对应任务书五点要求）

### 1. 环境定义

- **状态**：视频级特征向量（15872 维，可先经 PCA/线性层降维至 256 维便于策略网络处理）
- **动作**：离散动作空间，两类动作：
  - 增强动作：从算子库选择算子与强度，如 `去闪烁滤波 × {轻,中,强}`、`时域平滑 × 3档`、`不增强`
  - 打分动作：在增强序列终止后输出一个 MOS 预测
- **转移**：执行增强后对视频重新抽帧提取特征，进入下一状态；打分为终止动作
- **终止条件**：输出打分，或增强步数达到上限（如 3 步，防止无限循环）

### 2. 状态表示

复用本项目特征提取器（ResNet-50 多尺度 + ViT-B/16 双分支）输出的
15872 维视频级特征；RL 阶段冻结特征提取器，仅训练策略网络与价值网络。

### 3. 动作空间（示例）

| 动作 | 含义 |
|---|---|
| 0 | 不增强（直接打分） |
| 1-3 | 时域中值滤波（窗口 3/5/7） |
| 4-6 | 亮度抖动去除（低/中/高强度） |
| 7 | 输出当前视频的 MOS 打分（终止） |

### 4. 奖励函数

```
r = w1 × (-|score - MOS|)         # 与人工标注的一致性
  + w2 × SROCC 增益                # 全批次排序一致性
  - w3 × 增强保真度惩罚             # 过度增强导致失真
  + w4 × 稳定性奖励                 # 同一视频多次打分方差小
```

### 5. RL 算法：PPO

- 策略网络：MLP（256 → 128 → 动作数），价值网络同构输出单值
- 训练循环：批量采样轨迹（GGAE 估计优势）→ 多轮 PPO 裁剪目标更新 → 定期在验证集上评估 SROCC/PLCC
- 与半监督循环的关系：agent 的打分可视为"带策略的伪标签生成器"，可与 B 阶段伪标签池联动
